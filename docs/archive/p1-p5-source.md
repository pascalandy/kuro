# Provenance du corpus P1 à P5

Le dossier [`p1-p5/`](p1-p5/README.md) reproduit les 36 fichiers `README.md` et `docs/**` du commit Git `c478909`. Les chemins internes au snapshot restent inchangés pour préserver ses liens relatifs.

Le fichier [`p1-p5.sha256`](p1-p5.sha256) contient une empreinte SHA-256 pour chaque fichier. Depuis la racine du dépôt, exécuter la commande suivante pour contrôler le snapshot, le manifeste et les documents courants :

```bash
python3 scripts/verify_docs.py
```

Le snapshot est historique. Les documents placés directement à la racine de `docs/` décrivent le cadrage courant.
