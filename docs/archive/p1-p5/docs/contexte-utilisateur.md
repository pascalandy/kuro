## Demande et autorisations

L'utilisateur a approuvé un programme documentaire P1 à P5 pour préparer kuro. Il a demandé de continuer pendant son sommeil, avec un journal des décisions et des passations vérifiables.

L'autorisation couvre la rédaction, l'initialisation Git, les commits, le push et la création de PR sans nouvelle demande. Le coordinateur contrôle les revues et la publication. Les agents de phase n'exécutent pas ces actions avant sa revue.

L'utilisateur impose GPT-6 Astra avec effort medium. Chaque phase utilise un nouvel agent. Le coordinateur révise une phase avant de lancer la suivante. Un seul agent écrit dans un répertoire à un instant donné.

## Limites de l'autorisation

Le travail produit uniquement des documents Markdown, TSV ou texte, et les métadonnées Git nécessaires, dans le répertoire du projet kuro. Aucune installation, modification de la machine, application, prototype applicatif ou lecture des vrais médias n'est autorisée. Cette limite reste valable lorsque P5 est terminée.

Les ajustements de périmètre et de critères de réussite nécessitent une décision utilisateur. Une inconnue ne permet pas d'abaisser un critère. Les choix qui ne peuvent pas être tranchés restent des recommandations explicites.
