# Sources de l’inventaire Roon

Ce registre décrit un corpus primaire consulté le 2026-09-06 par l’auteur P2 et les deux chercheurs en lecture seule. Une consultation établit ce que publie Roon, pas le fonctionnement d’une installation. Roon n’a pas été exécuté. Version et build de référence inconnus.

Les articles d’aide ne donnent généralement pas de date de publication exploitable. Leur date de consultation ne date pas la fonction. Les mentions historiques et contradictions sont conservées. Aucun texte marketing ne constitue une mesure de performance. Les résumés ci-dessous et les comportements du TSV sont des paraphrases courtes.

Les identifiants sont stables et peuvent comporter des trous. Le [registre fonctionnel](inventaire-fonctions.tsv) utilise ces identifiants. Les limites transversales figurent dans [l’inventaire](inventaire-roon.md).
